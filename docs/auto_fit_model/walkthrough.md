# ウォークスルー: モデル自動調整モード（隠しモード）及びプリセット選択機能

テクスチャ画像の比率（アスペクト比）と指定した高さ（デフォルト100mm）・一周枚数（デフォルト1枚）から外周長を自動算出し、モデルの外周がちょうど一周するように幅・直径を決定した高精細3Dモデル（n角形柱、筒、お椀）をブラウザ上で動的生成する「自動調整モード（隠しモード）」を実装しました。また、固定サイズのプリセット（キューブ、筒、お椀、アップロード）を「通常モード」として整理しました。

---

## 1. 実装内容

### 新規モジュール: `js/proceduralModels.js`
- **寸法自動計算 (`computeAutoFitDimensions`)**:
  - 画像アスペクト比、指定高さ $H$、一周枚数 $N$ から展開幅 $W_{single} = H \times AR$、外周長 $C = N \times W_{single}$ を算出。
  - 形状ごとに半径 $R = C / (2\pi)$ や多角形の1辺 $s = C / n$、外接円半径 $R = \frac{s}{2\sin(\pi/n)}$ を正確に導出。
- **高精細 3D メッシュ生成**:
  - **筒（円柱 / Cylinder）**: 円周分割128〜256、高さ分割100〜200の滑らかなメッシュ。
  - **n角形柱（Regular n-gon Prism）**: 側面パネルの各面を縦横に約0.8〜1.0mmピッチでグリッド細分化し、ディスプレイスメントやスライスに対応したソリッドメッシュ。
  - **お椀（Bowl）**: 指定高さ $H$ と外径 $R$ に追従する回転体（LatheGeometry）メッシュ。
  - **キューブ（Cube）**: 50×50×50 mm、50分割。

### UIおよび隠しモード解禁ギミック (`index.html`, `style.css`)
- **通常モード表示**:
  - キューブ、筒、お椀、アップロード（ファイル選択）の4ボタンを並列配置。
- **隠しモードの解禁方法**:
  1. `Preset Models` ヘッダーを**ダブルクリック**、または右端の **`✦`** アイコンをクリック。
  2. URL パラメータに **`?mode=auto`** または **`?dev=1`** を付与してアクセス。
- **自動調整モードパネル**:
  - 形状ボタン（n角形柱、筒、お椀、アップロード）
  - 高さ入力（Height mm: デフォルト 100mm）
  - 一周枚数入力（Panel count: デフォルト 1）
  - n角形の角数入力（Sides: デフォルト 6、n角形柱選択時のみ表示）
  - リアルタイム寸法インフォメーション表示（外周長、直径、面幅）

### システム連携・自動更新 (`js/main.js`, `js/i18n.js`)
- テクスチャ変更時（プリセット選択、画像ファイルアップロード）に、自動調整モード中であれば自動でモデルを再計算・再生成。
- 自動調整モード時には、テクスチャが外周にぴったり一周フィットするよう円柱マッピング（Cylindrical Mapping）とスケール値を自動設定。
- 日英の多言語辞書キーを追加。

## 2. 検証結果

ブラウザ自動検証（Headless Browser Subagent）による実機テストを実施：
1. **URL起動 (`?mode=auto`)**:
   - 隠しモードが即座に解禁され、「Standard」と「Auto-fit (Image)」のタブが表示されることを確認。
2. **自動寸法計算とインフォメーション表示**:
   - デフォルト（高さ100mm, 枚数1, n=6）で、`Circumference: 100.0 mm · Dia: 31.8 mm · Face: 16.7 mm` のように寸法が正しく表示されることを確認。
3. **パラメータ変更のリアルタイム追従**:
   - 高さを 120 mm に変更 -> モデルが拡大し、外周 120.0 mm に即時更新。
   - 角数 n を 8 に変更 -> 8角形柱にリアルタイムに変形し、面幅が 15.0 mm に追従。
   - 形状を「Cylinder」に変更 -> 円柱モデルに切り替わり、角数入力がスマートに非表示になることを確認。
   - 形状を「Bowl」に変更 -> お椀モデルに切り替わることを確認。
4. **通常モードとの切り替え**:
   - 「Standard」タブをクリックすると従来の固定サイズプリセット（Cube, Cylinder, Bowl, Upload）が表示され、Bowl のロードが正常に行われることを確認。
   - 隠しトグルボタン（`✦`）でモード切替タブの表示/非表示が正常に動作することを確認。
