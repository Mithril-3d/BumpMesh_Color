# 実装計画: 交互積層（振り重ね）フラット段差標準化と層境界アラインメント

## 概要
交互積層（マルチツール振り重ね）において、フラットな面や直線部分に発生していた細かいジグザグ（波打ちノイズ）を完全に解消し、実際の高品質プリント品のように「フラットな部分は完全に直線・フラットなステップ」としてスライス・印刷できるように改善します。

## 原因分析
1. **「45° ルーバー庇」による層内Z傾斜とメッシュ解像度の干渉**:
   - 1層（厚み0.20mm）の内部で45度の庇を付けようとするため、頂点のZ座標の微小なばらつきに応じて突出量が0.10mm〜0.30mmの間でランダムに変動し、スライサーで切断したときに激しい波打ちノイズになっていた。
2. **層境界をまたぐ三角形の傾斜**:
   - 三角形メッシュのサイズ（refineLength 約0.5〜1.0mm）が層厚（0.20mm）より大きいため、三角形が凸層と凹層をまたぎ、境界付近で斜めに傾斜した面が生成されていた。

## 修正・改善内容

### 1. UIおよびデフォルト設定の更新 (`index.html`, `js/main.js`)
- 断面形状のデフォルトを「フラット段差（標準ステップ・推奨）」に変更。
- セレクタの選択肢表示を更新：
  - `0`: フラット段差（標準ステップ・推奨）
  - `1`: 45° ルーバー庇（他色シールド・実験的）
- `interleavedSettings.profileMode` の初期値を `0` に変更。

### 2. 変位計算コアロジックの更新 (`js/layerBlending.js`, `js/displacement.js`)
- `computeLouverDisplacement` の引数デフォルトを `profileMode = 0` に変更。
- フラット段差（`profileMode === 0`）時、頂点の Z 座標に起因する微小な傾斜や不均一性を完全に排除し、その層全体で完全に一様な変位（グラデーション比率に応じた突出量）を保証。

### 3. エクスポート時における層境界アラインメント最適化 (`js/main.js`)
- `sliceMeshWatertight` で各層ごとに切断された三角形群に対し、各層ブロックの側面ペリメーター（輪郭）が元のモデル形状（直線なら完全な直線、円なら完全な円弧）を100%維持するよう、層境界の頂点座標をアラインメント（整列）する。

## 検証計画
- キューブモデル（50x50x50mm）でのスライスシミュレーションを実行。
- 直線エッジにおけるX座標の誤差レンジ（ジグザグ振幅）が 0.0000mm（完全な直線）になることを自動検証。
