# 実装計画: テクスチャレイヤー機能 & スタンプ機能の導入 (v2.0.0)

## 1. 概要
本家 CNC Kitchen / Stefan Hermann 氏の `BumpMesh` (stlTexturizer) で追加された **Texture Layers (v1.4.0)** および **Stamp Mode (v1.5.0〜v1.5.1)** を `BumpMesh_Color` に移植・統合します。
安定稼働版（v1.7.2）への影響を完全に遮断するため、専用開発ブランチ `feature/texture-layers` 上で段階的に開発を進め、完了後に **v2.0.0** としてリリースします。

---

## 2. アーキテクチャと設計方針

### 2.1 本家 v1.4.0 〜 v1.5.1 の中核要素
1. **PaintTree (`js/paintTree.js`)**:
   - PrusaSlicer の TriangleSelector に倣った、三角形適応細分化ツリー。
   - ブラシで塗った部分だけを細分化し、ベースメッシュを破壊せずに高解像度なレイヤーマスク（塗り分け）を実現。
2. **Texture Layers (`layers[]`)**:
   - 1つのモデル上に最大4つのテクスチャレイヤーを保持。
   - 各レイヤーが独自のテクスチャ、投影設定（Planar, Cylindrical, Triplanar等）、凹凸設定（Amplitude）、塗りマスクを保持。
   - 合成モード: `Over`（上書き覆いかぶせ）または `Add`（凹凸加算）。
3. **Stamp Mode**:
   - テクスチャをタイリング（繰り返し）せず、モデル上のクリックした1点に1回だけバッジやロゴのように配置。
   - 面の向きに沿った「Surface normal」投影、裏面への突き抜けを防ぐオクルージョン（遮蔽）マップ。

### 2.2 BumpMesh_Color 独自機能との調和（共存ガード）
`BumpMesh_Color` には本家にない強力な独自機能（カラー量子化・マルチツール3MF、交互積層スライス、チューリング模様、Native Mesh UV 等）が多数存在します。これらとの衝突を防ぐため、以下の設計をとります：
- **通常テクスチャモード（モノクロ・立体凹凸）:**
  複数レイヤーの重ね合わせおよびスタンプ機能がフルに動作。
- **カラー＆マルチツールモード（AMS・マルチ押出機）:**
  カラーモード選択時は、第1レイヤー（ベースレイヤー）の設定を基準とし、複数レイヤーやスタンプは安全に制御（または第1レイヤー優先）。

## 3. 実装フェーズと詳細計画

### 【フェーズ 1】PaintTree と レイヤー基盤モジュール
1. `js/paintTree.js` および単体テストスクリプトの導入。
2. `index.html` にレイヤーストリップUI（レイヤー追加、タブ選択、表示/非表示、ブレンドモード切替）を追加。
3. `style.css` にレイヤーストリップのスタイリングを追加。
4. `js/main.js` に `layers[]` 配列ステート管理を導入。アクティブレイヤー切り替え時にサイドバーの各スライダー・セレクトボックスを正しく同期。

### 【フェーズ 2】プレビューシェーダー＆凹凸エクスポートの複数レイヤー合成
1. `js/previewMaterial.js`:
   - 最大4つのテクスチャサンプラー配列（`displacementMap[4]`）とレイヤーパラメータ（Uniform）の拡張。
   - バーテックス／フラグメントシェーダーでのレイヤー合成（Over / Add）の実装。
2. `js/displacement.js` & `js/exportPipeline.js`:
   - CPU側の複数レイヤー折りたたみ処理（`applyDisplacementLayers`）の移植。
   - エクスポート時の頂点ごとのレイヤー凹凸計算。

### 【フェーズ 3】スタンプ機能（Stamp Mode）の移植
1. `js/mapping.js`:
   - `stampFrame`（位置・法線・接線基底）および `stampUV` サンプリング計算の追加。
   - Surface Normal 投影アルゴリズムの追加。
2. `js/main.js` & `js/viewer.js`:
   - ビューポート上のクリックによるスタンプ配置、ドラッグ移動、ホイールによるサイズ変更。
   - スタンプオクルージョン（裏面遮蔽深度マップ）の生成とシェーダー連携。

### 【フェーズ 4】総合検証とローカライズ
1. 単一レイヤー時（従来の全機能）の互換性検証（100%リグレッションなし）。
2. 複数レイヤー時のプレビューおよび 3MF / STL エクスポート検証。
3. スタンプ配置とドラッグ移動、サイズ変更の動作検証。
4. 日本語（`js/i18n/ja.js`）をはじめとするローカライズ辞書の更新。
5. `walkthrough.md` の作成と v2.0.0 リリース準備。

## 4. 検証方法
- Node.js 自動検証スクリプトによる PaintTree・レイヤー合成ロジックの動作確認。
- ローカルサーバー（`http://localhost:5500/`）での実機ブラウザ操作検証。
- 生成された 3MF / STL モデルのスライサー（Bambu Studio, PrusaSlicer）でのプレビュー検証。
