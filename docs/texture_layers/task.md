## 既知の課題・保留中のメモ
- **マルチレイヤー時のカラーON表示異常**:
  - カラーOFF（ティール単色＋凹凸）の時は、レイヤー1（Blue Porcelain）とレイヤー2（Ichimatsu）が面ごとに正常に分離されて凹凸が表示される。
  - カラーON（3Dプレビューで色を表示）にすると、凹凸は面ごとに分かれているが、**色情報（カラーテクスチャ）がレイヤーごとのマスク（`layerMask`）を反映せず、モデル全体にアクティブレイヤー（Ichimatsuの市松模様色）が一律で適用されてしまう**。
  - 原因: `previewMaterial.js` において、凹凸（バンプ）はレイヤーごとのウェイト `w[l]` で合成しているが、カラー計算（`computeColorAtPoint` / `colorMap`）は単一のテクスチャおよびレイヤー0のUVパラメータのみを使用しており、色レイヤーのマルチサンプリング／マスク合成（Over）に対応していないため。
  - 今後の方針: カラーテクスチャ側もレイヤーごとのマスク（`layerMask`）に応じて合成するか、レイヤーごとのカラーマップ対応を行う。
