# 実装計画書: 3Dメッシュ表面チューリングパターン生成（隠し機能その2：アプローチB 均一リメッシュ頂点反応拡散）

## 1. 概要と目標
本実装では、INSYDIUM nxBiologic のような**「3Dモデルの表面上で直接シミュレーションされ、這うように自己組織化して成長するチューリングパターン（反応拡散系 / Reaction-Diffusion）」**を、BumpMesh_Color の**テクスチャ隠し機能その2（アプローチB: 均一リメッシュ＋頂点グラフ拡散）**として実装します。

2Dテクスチャ投影（UVマッピング）では避けられない「側面の引き伸ばし歪み」や「シーム（継ぎ目）での分断」が発生せず、任意の3Dモデル表面上にシームレスかつ有機的な立体迷路・サンゴ・スポット模様を生成し、そのまま3Dプリント可能な凹凸変位メッシュとして確定・エクスポートできるようにします。

まずはユーザーの要件に基づき、**カラー処理は行わず、立体変位（モノクロバンプ/ディスプレイスメント）に特化**して安定かつ高速な体験を提供します。

## 2. アーキテクチャと数理モデル

### 2.1 Gray-Scott 反応拡散方程式
2つの仮想化学物質 $U$（基質）と $V$（活性剤）の濃度分布を時間発展させます：
$$\frac{\partial U}{\partial t} = D_u \Delta U - U V^2 + F (1 - U)$$
$$\frac{\partial V}{\partial t} = D_v \Delta V + U V^2 - (F + k) V$$

- **パラメータ設定**:
  - $D_u = 0.20, D_v = 0.10$（拡散係数）
  - $F$（供給率 / Feed rate）: $0.020 \sim 0.060$
  - $k$（枯渇率 / Kill rate）: $0.050 \sim 0.070$
  - プリセット例：
    - **迷路・脳皺 (Maze / Brain)**: $F = 0.030, k = 0.062$（細いストライプ状に自己組織化）
    - **サンゴ・指紋 (Coral / Fingerprint)**: $F = 0.054, k = 0.062$（枝分かれ構造）
    - **ヒョウ柄スポット (Spots)**: $F = 0.034, k = 0.065$（水玉状）
    - **波紋 (Waves / Solitons)**: $F = 0.014, k = 0.047$

### 2.2 均一メッシュ上の離散ラプラシアン演算子 $\Delta$
非インデックスの 3D メッシュに対し、`QuantizedPointMap` を用いて一意な頂点 $i = 0 \dots N-1$ を集約し、各頂点に接続するエッジから隣接頂点リスト $\mathcal{N}(i)$ を構築します。

各頂点 $i$ における空間拡散項（離散ラプラシアン）は、隣接点間のユークリッド距離 $d_{ij} = \|p_j - p_i\|$ の逆数重み $w_{ij} = 1 / d_{ij}$ を用いて正規化計算します：
$$w_{ij}' = \frac{w_{ij}}{\sum_{k \in \mathcal{N}(i)} w_{ik}}$$
$$\Delta U_i = \sum_{j \in \mathcal{N}(i)} w_{ij}' (U_j - U_i)$$

均一リメッシュ（`subdivide` + `regularizeMesh`）により辺の長さがほぼ一定に揃えられているため、ラプラシアンの等方性が極めて高く保たれ、歪みのない美しいパターンが自己組織化されます。

## 3. 実装モジュール構成

### 3.1 `js/meshTuring.js`（新規モジュール）
- **メッシュグラフ構築 (`buildMeshGraph(geometry)`)**:
  - 頂点座標の量子化・重複排除。
  - ユニーク頂点ごとの位置、法線、隣接頂点インデックス、正規化逆距離重みのキャッシュ。
  - 元の `geometry.attributes.position` の各インデックスとユニーク頂点 ID との相互マッピング配列。
- **シミュレータークラス (`MeshTuringSimulator`)**:
  - `Float32Array` による $U, V$ 濃度配列バッファ（Ping-Pong 用ダブルバッファ）。
  - `seedAtPoint(worldPoint, radius)`: Three.jsのRaycasterで取得したワールド座標近傍の頂点に $V=1.0$ のシードを注入。
  - `seedRandom(count)`: ランダムな複数箇所にシード注入。
  - `step(subSteps)`: 1フレームあたり 5〜10 ステップのオイラー更新を実行。
  - `getDisplacedGeometry(height)`: 最終的な濃度 $V$（または $1-U$）に基づき、各頂点を法線方向に押し出した新規 `BufferGeometry` を生成。

### 3.2 UI とコントローラー（隠し機能その2）
- **トリガー**:
  - `Displacement Map` セクションヘッダーの `✦` の隣に、秘密のアイコンボタン **`🧬`**（`#secret-turing-trigger`）を追加。
  - URL パラメータ `?turing=1` または `?secret=2` でも起動可能。
- **操作パネル (`#turing-modal` またはオーバーレイパネル)**:
  - **プリセット切替**: 「迷路（Maze）」「サンゴ（Coral）」「スポット（Spots）」「波紋（Waves）」
  - **パラメータスライダー**: Feed $F$、Kill $k$、シミュレーション速度、変位高さ（mm）
  - **シミュレーション制御**:
    - **再生 / 一時停止 (▶ / ⏸)**
    - **ステップ進行 (⏭)**
    - **リセット (↺)**
  - **シード配置**:
    - 「クリックしてシード配置」モード（オンにすると、3Dビュー上のモデルをクリックした位置にシードが落ちる）
    - 「ランダムシード」ボタン
  - **確定ボタン**:
    - 「**モデルに変位を適用 (Apply to Model)**」: 生成されたチューリングパターンを実メッシュ変位として確定し、BumpMeshのメインパイプライン（STL / 3MFエクスポート等）に直結。

## 4. ユーザー体験（UX）のフロー
1. ユーザーが画面上の `🧬` アイコンをクリック。
2. 「3D Mesh Turing Pattern」パネルが開き、現在のモデルが自動的に均一リメッシュ（等方性細分割）される。
3. ユーザーがモデル上の好きな場所（例えば足の甲、頭部、側面など）をクリックすると、そこにシード（種）が注入される。
4. ▶ 再生ボタンを押すと、クリックした場所からまるで生き物やサンゴのように、メッシュ表面を有機的な迷路模様がリアルタイムに這って広がっていく。
5. 好きな広がり具合で ⏸ 一時停止。
6. 「モデルに変位を適用」をクリックすると、その模様が立体レリーフ（変位）としてメッシュに焼き込まれる。
7. 通常通り「STLをエクスポート」や「3MFをエクスポート」で3Dプリンターで印刷可能！
