# タスク: モデル自動調整モード（隠しモード）及びプリセット選択機能の追加

## 概要
画像の比率（アスペクト比）に合わせて、指定した高さ（デフォルト100mm）と一周の画像枚数（デフォルト1枚）から外周長を自動計算し、ピッタリ一周する3Dモデル（n角形柱、筒、お椀）をブラウザ上で高精細に自動生成する「自動調整モード（隠しモード）」を実装した。併せて、既存の固定サイズプリセット（キューブ、筒、お椀、アップロード）を「通常モード」として整理した。
