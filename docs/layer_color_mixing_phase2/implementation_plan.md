# 実装計画: 【Phase 2】「振り重ね」による積層混色・マルチツール階調表現 (Layer Blending / HueForge-style)

## 概要
FDM 3Dプリンタのフィラメントが持つ光透過性（Transmission Distance / 透過度）を活用し、複数色のフィラメントを特定順序で層状に重ね合わせることで、限られたツール数（2〜8色）から滑らかな中間調・混色グラデーション（リトフェーン／HueForgeスタイル）を生成・プレビュー・3MFエクスポートする新機能「**振り重ね積層混色（Layer Blending）**」を実装します。

---

## ユーザー確認事項 (User Review Required)

> [!IMPORTANT]
> **積層混色の方式とスライサー互換性について**:
> 1. **3MFエクスポート形式**:
>    - Phase 1 で確立した **100% Manifold / 0 オープンエッジの単一水密ソリッド + TriangleSelector ファセットペイント** を本機能でも標準採用します。
>    - 各三角形の高さ（変位量）に基づき最表面のツールを割り当てることで、PrusaSlicer / Bambu Studio / OrcaSlicer で開いた際にエラーやプロンプトなしで層状マルチツールとして認識されます。

> 3. **UIレイアウト**:
>    - 「Color & Multi-Tool」パネル内に、モード切り替え（`カラー量子化 (Phase 1)` / `振り重ね積層混色 (Phase 2)`）を導入します。

## 主な機能とアーキテクチャ

```mermaid
graph TD
    A[テクスチャ画像 / ハイトマップ] --> B[Layer Blending モジュール (layerBlending.js)]
    B --> C[光透過シミュレーション (Beer-Lambert / Alpha Blending)]
    C --> D[3Dビューポート (previewMaterial.js シェーダー拡張)]
    B --> E[スライス境界計算 (レイヤー高さ・閾値スナップ)]
    E --> F[TriangleSelector ペイント判定 (exporter.js)]
    F --> G[100% 水密・Manifold Multi-Tool 3MF 出力]
    E --> H[Slicing Guide UI (レイヤー別フィラメント交換指示)]
```

### 1. 混色・厚み計算モジュール (`js/layerBlending.js`)
- **透過混色シミュレーション**:
  - フィラメントの色 $C_k$ と透過係数（Transmission Distance）に基づき、各層の厚み $t_k(u, v)$ から最終的な透過色を合成。
  - Beer-Lambert 則またはアルファ透過合成により、下の濃い色（例: 黒）の上に薄い色（例: 青・黄・白）が乗った際の中間階調を光学計算。
- **高さスライス閾値（Height Thresholds）の算出**:
  - 各ツールの境界高さ $h_0, h_1, \dots, h_K$ を管理。
  - レイヤー高さ（例: 0.08mm, 0.16mm, 0.20mm）への自動スナップ機能。
  - メッシュの局所変位またはZ高さから、各三角形の該当ツールIDを特定。

### 2. GUI コンポーネント (`index.html`, `style.css`, `js/main.js`)
- **モード切り替え**:
  - `[量子化 (Quantization)]` / `[振り重ね (Layer Blending)]` タブ。
- **ツールスタッキング順序コントロール (Tool Order)**:
  - 底層（Base）から最上層（Highlight）への並び順を視覚的に表示。
  - 上下移動ボタン（↑ / ↓）による直感的な順序変更。
- **レイヤー境界スライダー**:
  - 各ツールの開始・終了高さ（mm または %）をスライダーで直感調整。
  - 推奨値自動計算（等間隔または輝度ヒストグラムに基づく最適閾値）。
- **スライシングガイド (Slicing Guide)**:
  - 「何mm（第何レイヤー）でどの色に切り替えるか」を一覧表示し、ワンクリックでクリップボードにコピー可能。

### 3. 3Dプレビューとシェーダー (`js/previewMaterial.js`)
- 振り重ねモード用のカスタムシェーダーロジックを追加。
- 頂点/フラグメントシェーダーで、変位高さに応じた透過積層混色をリアルタイムレンダリング。
- スライダーを動かした瞬間にビューポート上の混色グラデーションがリアルタイム追従。

### 4. 3MFエクスポート連携 (`js/exporter.js`)
- 振り重ねモード選択時、各ファセットの変位高さに基づき、TriangleSelectorのペイントコード（`'4'`, `'8'`, `'0C'`, `'1C'`...）を割り当て。
- 0 オープンエッジ・100% 水密マニホールドを維持したまま、レイヤー境界で完璧にツールが切り替わる 3MF を生成。

## 検証手順

### 1. プレビューとUIの動作検証 (Browser Verification)
- ブラウザ上で「振り重ね混色」モードに切り替え。
- 4色（黒、青、黄、白 など）の積層順序や高さ閾値を変更した際、3Dプレビューで美しい透過グラデーションがリアルタイム表示されることを確認。
- レイヤー厚みスライダーやスライスガイドの数値が正しく更新されることを確認。

### 2. PrusaSlicer CLI によるエクスポート検証 (Automated CLI Test)
- 振り重ねモードで出力した 3MF ファイルを PrusaSlicer CLI で解析：
  - `open_edges = 0`
  - `manifold = yes`
  - `number_of_parts = 1`
  - レイヤー別ツールチェンジがスライサー上で正しく認識されることを確認。

### 3. Bambu Studio / OrcaSlicer 互換性
- 生成された 3MF をスライサーに読み込ませ、余計なプロンプトやオープンエッジ警告が出ないことを確認。
