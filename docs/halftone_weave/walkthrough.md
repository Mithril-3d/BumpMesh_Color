# Walkthrough: ハーフトーン編み（Halftone Weave）機能の実装

## 変更内容の概要
meditat38 氏の NozzleBoss フォークによるフルカラー・ハーフトーン造形手法の知見を取り入れ、BumpMesh_Color に新規プロファイル **「Profile 5: ハーフトーン編み（内壁固定・写真・多色向け）」** を追加しました。既存のプロファイル（0: フラット, 1: 45°ルーバー, 2: 正弦波, 3: 三角波, 4: 矩形ブロック）は一切変更せず互換性を保っています。

### 1. 主な特徴・改善ポイント
- **内壁アンカー固定構造 (Anchored Inner Wall)**:
  - 従来のブロック編み（Profile 4）では壁全体が内外に平行シフトしていたため、突出量が大きい（0.8mm〜2.0mm）場合に前後の層との接触面積が減少し、空打ちや垂れのリスクがありました。
  - ハーフトーン編みでは、内壁半径 `r_in = r_base - wallThickness` を円筒ベース上に常時固定。全層の内壁同士が100%同心円上に積み重なり、強固なバックボーン（芯）を形成します。
- **見せたい色のみが外側ループとして飛び出す制御**:
  - 各色レイヤーにおいて、見せたい箇所では露出量に応じて外壁が外側へループ状（幅・突出）に飛び出し、隠したい箇所（露出度 0）ではベース円筒（`disp = 0`）に戻って奥に引っ込みます。
- **2色モードでのハイライト結合（フラットリブ化）**:
  - 2色の写真印刷時など、高明度・ハイライト領域では波形の山が横方向に広がり、隣り合う周期と繋がって連続したフラットなリブを形成。実物の作例に見られる「白の広い面では連続して飛び出る」質感を再現。
- **多色モード（3〜4色）での安定アンカー**:
  - 3色以上では、他色レイヤーが引っ込んでいる間に宙吊りになるのを防ぐため、各周期の谷（Trough）がベース円筒面（`disp = 0`）に確実に帰着し、ベース層との溶着を保証します。
- **シェーダー（WebGL）プレビュー完全同期**:
  - `js/previewMaterial.js` の GLSL バーテックス/フラグメントシェーダーに Profile 5 の変位・カラー合成式を完全移植し、画面上の3Dプレビューと実際の出力メッシュ（3MF）が一致します。
