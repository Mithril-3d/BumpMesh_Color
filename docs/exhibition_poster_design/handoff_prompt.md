```markdown
現在、3Dプリンター愛好家イベント（3DPの集い）での展示用として作成したA4卓上POP（チラシ）「exhibition_poster_a4.html」のデザイン作業を引き継ぎたいです。

まずは以下のデザイン方針・前提条件・ファイル構成を把握してください。

### 1. 前提と目的
- プロダクト：BumpMesh_Color（ブラウザ完結で画像から凹凸＆マルチカラー3MFを生成するWebツール）
- 展示状況：実機プリンターの調子が悪くプリント実物の展示が難しいため、「実写造形写真」「スライサーの積層画面」「UIプレビュー」の3枚を並べて凄さを伝えるA4縦の卓上POP。
- 印刷仕様：ブラウザで開いて `Cmd + P` でA4縦1枚にジャストフィットするCSS（@page, @media print 対応）。

### 2. デザインルール（※重要・厳守）
- 【完全ライトテーマ】：ダークテーマや黒背景の強調ボックスはNG。清潔感のある白ベースで統一すること。
- 【カラーパレットの統一】：無駄に色数を増やさない。キーカラーを「ロイヤルブルー（#2563eb / #1e40af）」と「スレートグレー（#0f172a / #334155 / #64748b）」に一本化し、赤や緑・紫などの唐突なアクセントカラーは使わないこと。
- 【A4縦1枚に収める】：要素を増やしすぎて2ページ目に溢れないよう、パディングやフォントサイズのバランスを維持すること。

### 3. 主なファイルと構成要素（exhibition_poster_a4.html）
- ヘッダー：`logo.png`、タイトル、オープンソース/完全無料バッジ
- メインキャッチ：薄いブルー（#eff6ff）の強調枠＋「画像を貼るだけ」のコピー＋対応スライサーピル
- 3大特徴カード：上部ボーダーをブルー（#2563eb）で統一した3列グリッド＋タグ
- ビジュアル3連ギャラリー：
  1. `docs/images/interleaved_print_sample.jpg`（実際のプリント造形例）
  2. `docs/images/interleaved_slicer_sliced.jpg`（スライサー即対応）
  3. `docs/images/overview_hero.png`（リアルタイムGPUビュー）
- 実演案内枠：ライトブルー背景＋ブルーの「実演中！」バッジ（「お好きな画像でその場で立体化できます」）
- フッター：`docs/images/qr_bumpmesh.png`（特大QRコード）＋アクセス誘導＋作者・GitHub情報
```
