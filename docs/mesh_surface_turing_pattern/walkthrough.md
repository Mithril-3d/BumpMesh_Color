# ウォークスルー: 3Dメッシュ表面チューリングパターン生成（隠し機能その2：アプローチB 均一リメッシュ頂点反応拡散）

ユーザーの要望に基づき、**「テクスチャ隠し機能その2」**として、INSYDIUM nxBiologic にインスパイアされた**「3Dモデルの表面上で直接シミュレーションされ、這うように自己組織化して成長するチューリングパターン（反応拡散系 / Reaction-Diffusion）」**を、**アプローチB（均一リメッシュ ＋ 頂点グラフ拡散）**により実装しました。

新ブランチ **`feature/mesh-turing-pattern`** 上で作業を行い、既存のBumpMesh_Color機能やマルチカラーパイプラインを壊すことなく、完全に独立した機能として動作することを確認しました。

## 1. アプローチB（均一リメッシュ＋頂点グラフ拡散）の仕組み

2Dテクスチャのプロジェクション（UVマッピング）では、角や側面でパターンの引き伸ばしや継ぎ目（シーム）の断裂が発生します。
本機能では、**3Dメッシュのトポロジー（頂点とエッジの接続関係）をグラフ構造として直接解析**し、表面上で Gray-Scott 反応拡散方程式を離散的に解きます。

### 1.1 数理モデル (Gray-Scott Reaction-Diffusion)
$$\frac{\partial U}{\partial t} = D_u \Delta U - U V^2 + F (1 - U)$$
$$\frac{\partial V}{\partial t} = D_v \Delta V + U V^2 - (F + k) V$$

- **基質 $U$ と活性剤 $V$**: 初期状態では全頂点が $U=1.0, V=0.0$（平坦）。
- **シード投入**: ユーザーがモデル上をクリック、またはランダム注入した地点に活性剤 $V=1.0$ を注入。
- **離散ラプラシアン演算子**:
  各頂点 $i$ の隣接頂点 $j \in \mathcal{N}(i)$ とのユークリッド距離 $d_{ij} = \|p_j - p_i\|$ の逆数重み $w_{ij} = 1 / d_{ij}$ を用いて正規化したラプラス・ベルトラミ近似演算を適用：
  $$\Delta U_i = \sum_{j \in \mathcal{N}(i)} \frac{w_{ij}}{\sum_k w_{ik}} (U_j - U_i)$$
- **均一リメッシュ連携**:
  元のメッシュがどんな粗いポリゴン（例: 直方体の6面12ポリゴン）であっても、`subdivide` ＋ `regularizeMesh`（スリバー解消）によって等方的な均一三角形メッシュ（約1.5万〜3.5万頂点）に整えてからシミュレーションを実行するため、パターンが均一・滑らかに広がります。

## 3. UIとユーザー操作フロー

1. **隠し機能の起動**:
   - `Displacement Map` セクションタイトルの右側にある秘密のアイコン **`🧬`**（または URL パラメータ `?turing=1`）をクリックすると、緑色の「3D Mesh Turing Pattern」ボタンおよび右上のフローティングパネルが出現。
2. **メッシュ準備**:
   - 目標エッジ長（デフォルト 1.2mm）で「⚡ メッシュを均一化して準備」をクリック（パネル展開時に自動実行）。
3. **パターンプリセット選択**:
   - 🧠 **迷路 / 脳皺 (Maze)** ($F=0.030, k=0.062$)
   - 🪸 **サンゴ / 指紋 (Coral)** ($F=0.054, k=0.062$)
   - 🐆 **ヒョウ柄 / 水玉 (Spots)** ($F=0.034, k=0.065$)
   - 🌊 **波紋 / パルス (Waves)** ($F=0.014, k=0.047$)
   - 🌀 **有機渦巻 (Spirals)** ($F=0.018, k=0.051$)
4. **シード（発生源）の投入**:
   - 「🎯 モデルをクリックして注入」がONのとき、3Dモデル上の好きな場所（例えば足の甲や正面）をクリックすると、その地点に化学物質が注入される。
   - 「🎲 ランダム」で複数箇所に同時注入も可能。
5. **シミュレーション実行**:
   - 「▶ 成長を開始」を押すと、リアルタイム（60fps）でパターンがメッシュ表面を這うように立体的に盛り上がりながら成長！
   - 好きな成長段階で「⏸ 一時停止」。
6. **モデルに変位を適用**:
   - 「✨ モデルに変位を適用」をクリックすると、現在の立体模様がメッシュのジオメトリとして確定され、通常のBumpMesh画面に戻ってSTL / 3MFエクスポートが可能。

## 4. 動作検証結果

CDP (Chrome DevTools Protocol) によるヘッドレス自動テストを実施し、以下の動作を確認しました：

1. **均一リメッシュとグラフ構築**:
   - 立方体メッシュ（Cube）に対し、目標エッジ長 1.2mm でリメッシュを実行し、**30,002 頂点** の一様グラフが瞬時に構築されることを確認。
2. **シード注入と反応拡散ステップ**:
   - ランダムシード投入後、250ステップの反応拡散を高速オイラー積分（毎フレーム8ステップ×30回超）で計算。
3. **エッジを跨ぐシームレスな拡散**:
   - 立方体の正面、上面、側面にわたり、角（エッジ）で破綻することなく同心円状の有機的な立体波紋がシームレスに伝搬することを確認。
4. **モデル変位確定 (Apply to Model)**:
   - 確定処理により、法線方向に高さ 1.5mm の立体レリーフがジオメトリに焼き込まれ、パネルが正常に閉じることを確認。

## 6. フィードバック改善（指向性解消・除外領域保護・水玉安定化・シード半径調整）

ユーザーフィードバックに基づき、以下の4つの重要課題を解決・改善しました：

### 6.1 コタンジェント・ラプラシアンによる縦指向性の完全解消
- **原因分析**:
  従来の距離逆数重みラプラシアン（Graph Laplacian）は無次元の頂点ホップで拡散していたため、円柱などのモデル（縦方向と周方向でエッジ長・対角線比率が異なる格子構造）では、エッジ密度が高い縦方向に拡散速度が極端に偏り（アスペクト比 1.41〜2.0 の縦長ブロック・縦縞）、不自然な指向性が発生していました。
- **改善策**:
  離散微分幾何学の標準である **コタンジェント・ラプラス・ベルトラミ作用素（Cotangent Laplace-Beltrami Operator）** を実装：
  $$w_{ij} = \frac{1}{2} (\cot \alpha_{ij} + \cot \beta_{ij})$$
  $$(\Delta f)_i = \frac{1}{A_i} \sum_{j \in \mathcal{N}(i)} w_{ij} (f_j - f_i)$$
  各頂点のバリセントリック双対面積 $A_i$（$\text{mm}^2$ 単位）と幾何学的角度から厳密に離散化し、格子やエッジの向きによる偏りを完全に相殺。
- **検証結果**:
  円柱モデルにおける拡散アスペクト比（縦/周比）が従来の **1.41〜2.0** から **1.03（真円）** へ劇的改善。歪みのない等方的な有機成長を実現しました。

![クリックシードからの真円有機成長](/Users/phaizmithriln/.gemini/antigravity-ide/brain/0b54c1b5-7af6-42ae-bb66-b325e019d6d1/screenshot_click_seed_growth.png)

### 6.2 除外ペイント（Exclusion Paint）領域への侵入ブロック
- **改善策**:
  ユーザーがペイントツールで除外指定した面（`excludedFaces`）から `buildFaceWeights` を経由してリメッシュ後頂点属性 `excludeWeight` を追跡。
  シミュレーター内部で除外頂点マスク（`excludedMask`）を構築し、除外頂点は濃度 $V=0.0, U=1.0$ に完全固定（ディリクレ境界条件）とすることで、パターンが除外領域を跨いで伝播しないように保護しました。
- **検証結果**:
  円柱の天面（および除外指定部）への化学物質侵入テストで、侵入頂点数 **0（100%遮断）** を確認。

![円柱全体に広がる迷路パターンと除外保護](/Users/phaizmithriln/.gemini/antigravity-ide/brain/0b54c1b5-7af6-42ae-bb66-b325e019d6d1/screenshot_turing_maze.png)

### 6.3 ヒョウ柄 / 水玉（Spots）プリセットの持続・自己増殖化
- **原因分析**:
  従来の $F=0.034, k=0.065$ は過剰拡散による死滅境界（decay）に位置しており、投入直後に化学物質が枯渇して消滅していました。
- **改善策**:
  自己複製スポットが安定して持続する Gray-Scott 安定解（$F=0.034, k=0.063$）にチューニング。
- **検証結果**:
  400ステップ経過後も **5,026 頂点** のアクティブスポットが自己分裂・増殖しながら鮮明に持続することを確認。

### 6.4 シード投入半径（直径）調整スライダーの追加
- **UI拡張**:
  「3. シード（発生源）投入」エリアに **シード半径スライダー（1.0mm〜15.0mm、初期値 3.0mm）** を追加。
- **操作性**:
  極小スポット（直径 2.0mm〜）から大きな塊まで、好みのサイズでモデル上に繊細にシードを植え付けることが可能になりました。
