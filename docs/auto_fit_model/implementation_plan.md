# 実装計画: モデル自動サイズ調整モード（隠しモード）及びプリセット選択機能

テクスチャ画像の比率と指定した高さ・一周枚数に合わせて、外周がちょうど一周する3Dモデル（n角形柱、筒、お椀）をブラウザ上で高精細に自動生成する「自動調整モード（隠しモード）」を実装します。また、既存の固定サイズプリセット（キューブ、筒、お椀、アップロード）を「通常モード」として整理します。

---

## 1. 概要と仕様

### モード構成
1. **通常モード（固定サイズプリセット）**:
   - **キューブ**: 50×50×50 mm
   - **筒**: 直径 80 mm, 高さ 100 mm
   - **お椀**: 直径 80 mm, 高さ 45 mm
   - **アップロード**: ユーザー自身のSTL / OBJ / 3MF / STEPファイルを読み込み
2. **自動調整モード（隠しモード・動的生成）**:
   - 形状選択:
     - **n角形柱**: 辺数 $n \ge 3$（デフォルト: 6）
     - **筒（円柱）**
     - **お椀（Bowl）**
     - **アップロード**
   - パラメータ:
     - **高さ $H$**: デフォルト 100 mm（数値入力）
     - **一周の画像枚数 $N$**: デフォルト 1 枚（数値入力、1, 2, 3...）
     - **角数 $n$**: n角形柱選択時のみ表示（デフォルト 6、3以上の整数）
   - **自動サイズ計算ロジック**:
     - 選択中の画像アスペクト比 $AR = W_{img} / H_{img}$ を取得。
     - 画像1枚の展開幅 $W_{single} = H \times AR$
     - 外周長 $C = N \times W_{single} = N \times H \times AR$
     - **各形状の寸法導出**:
       - **筒**: 半径 $R = C / (2\pi)$、高さ $H$
       - **n角形柱**: 1辺の長さ $s = C / n$、外接円半径 $R = \frac{s}{2\sin(\pi/n)}$、高さ $H$
       - **お椀**: 最大外周（リム）を $C$ に合わせ、最大半径 $R_{outer} = C / (2\pi)$、高さ $H$
     - 画像を差し替えた時や、高さ・枚数・角数を変更した時に、モデルが自動再生成される。

### STL（メッシュ）の細かさ設計
- ディスプレイスメントやマルチカラー交互積層が綺麗に乗るよう、「まぁまぁ細かい」メッシュを生成します：
  - **筒**: 円周分割（radialSegments）128〜256、高さ分割（heightSegments）100〜200（約0.5〜1mmピッチ）。
  - **n角形柱**: 側面各パネルを平面グリッドとして分割（幅方向・高さ方向ともに約0.5〜1mmピッチ）。底面・上面もファンまたはグリッド分割。
  - **お椀**: LatheGeometry の回転分割 128〜256、垂直方向 60〜100ステップ。

### 隠しモードへのアクセス方法
- 「Preset Models」ラベルをダブルクリック、または右端の隠しボタン（ギア/マジックワンドアイコン）、または URL パラメータ `?mode=auto` や `?dev=1` で有効化。
- 有効化されると、モード切り替えタブまたは展開UIが現れ、「通常」と「自動調整」を切り替え可能になります。

## 3. 検証計画

### 動作検証
1. **通常モード動作確認**:
   - キューブ、筒、お椀、アップロードがこれまで通り正常に読み込めること。
2. **隠しモード解禁確認**:
   - ラベルのダブルクリックまたはURLパラメータ `?mode=auto` で自動調整モードパネルが表示されること。
3. **自動サイズ計算と生成の確認**:
   - 様々なアスペクト比の画像（1:1、16:9、縦長など）を選択し、筒やn角形柱の外周が正しく計算されてメッシュが生成されること。
   - 高さを変更（例: 50mm, 150mm）したとき、比率を維持したまま外周も連動して拡大縮小すること。
   - 一周枚数を「1」「2」「3」などに変更したとき、外周が2倍・3倍になること。
   - n角形柱の辺数（3, 4, 5, 6, 8等）を変更し、正しい正多角形柱が生成されること。
4. **マッピングとスライスの確認**:
   - 円柱マッピング等でテクスチャが外周にぴったり一周（または指定枚数）貼られること。
   - 交互積層スライスや3MFエクスポートがエラーなく動作すること。
