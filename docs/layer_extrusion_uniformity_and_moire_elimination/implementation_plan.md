# 実装計画: 交互積層における突出量均一化およびモアレ・微弱凹凸の完全解消

## 背景と根本原因
スライサーでのスライス断面において、同じ色（白）の領域であるにもかかわらず、白層の突き出し量が長い層と短い層で周期的に波打つ現象（4層周期モアレ）、および同一層の直線部分に微小な凹凸（ブツブツ）が残る問題が発生していた。

### 根本原因の特定
1. **レイヤー境界との非同期頂点による斜め坂道の発生**:
   細分化（subdivision）によって生成された頂点の Z 座標はレイヤー厚さ（0.20mm）と同期しておらず（0.5mm〜1.0mmピッチ）、三角形が複数のレイヤー境界を跨いでいた。
   スライシング前に頂点ディスプレイスメントを適用したため、レイヤー境界を跨ぐ三角形が斜めの坂道（chamfer）となり、その後の `sliceMeshWatertight` 切断時に坂道の途中の半端な変位値（25.11mmなど）が固定されていた。
2. **QEMデシメーションによる微小段差の破壊**:
   ディスプレイスメント後にデシメーション（QEMメッシュ削減）および平坦面ハーベスティングが実行されたため、0.20mm の微細な段差形状が崩れ、微小な凹凸（ブツブツ）が生じていた。

## 解決方針
1. **交互積層モード（`colorSubMode === 1`）専用の直列パイプラインの導入**:
   パイプライン初期段階での事前ディスプレイスメントおよびデシメーションをバイパスし、高精度な未変位ベースメッシュを取得。
2. **未変位ベースメッシュのレイヤースライス**:
   未変位の完全なベース形状（直方体なら側面 X=25.0000mm）を、Z=0 接地した上で `sliceMeshWatertight` により各レイヤー境界（Z = 0.005, 0.205, 0.405...）で水平切断。
3. **スライス後の層整合ディスプレイスメント (`applyLayerAlignedDisplacement`)**:
   各層に属する三角形に対して、その層のアクティブツール（Tool 1なら白、Tool 2なら青）およびテクスチャサンプリングに基づいて法線方向の変位を厳密に適用。
   - すべての白層（Layer 0, 2, 4, 6...）の側面頂点は、例外なく 100% 厳密に同一の突出量（Base + 0.3000mm）に揃う。
   - 坂道補間やQEMによる崩れが物理的に発生しないため、モアレおよびブツブツが完全に根絶される。
4. **バージョン管理**:
   - `APP_VERSION` を `1.0.1` に更新
   - ヘッダー表示を `BumpMesh_Color v1.0.1 by @Mithril_MEX` に更新
