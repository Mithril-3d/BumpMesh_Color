# 実装計画: プロシージャル・テクスチャジェネレータ（3色パターン・隠しモード）

## 1. 概要
3色（背景1色、グラデーション2色）によるドット・多角形グラデーション模様をプロシージャルに生成するジェネレータを構築します。
添付された画像（黒背景、下部が大きなオレンジドット、上に向かってドットが縮小しつつ白へグラデーションする千鳥配置パターン）をはじめとする多彩でスタイリッシュな幾何学模様を、パラメータ指定で即座に生成し、BumpMeshの3Dモデルへ直接適用・または高解像度PNGとしてダウンロードできるようにします。

---

## 2. アーキテクチャとファイル構成

### 新規ファイル
1. **`js/textureGenerator.js`**:
   - キャンバス描画エンジン（オフスクリーンキャンバス対応）。
   - シェイプ描画関数（円、正n角形、星、リング、十字、ひし形など）。
   - 配列・レイアウトアルゴリズム：
     - 千鳥格子（Staggered / Hexagonal）および直交格子（Grid）。
     - 各ドットの位置 $(x, y)$ におけるグラデーション重み $t \in [0, 1]$ とスケール係数の算出。
     - レイアウトモード：
       - `vertical`: 下から上（または上から下）へサイズ大→小、色A→色Bへ遷移。
       - `horizontal_blend`: 左右で色が溶け合い反転・交換するフュージョンパターン。
       - `wave`: サイン波状にうねりながら色とサイズが変化。
       - `radial`: 中心から外周へ放射状に拡大・縮小。
       - `diagonal`: 45度斜め方向のグラデーション。
       - `noise`: 有機的な擬似ランダムノイズによる揺らぎ。
     - シームレス・シリンダーラップ（左右境界で周期が完全に一致するよう横方向列数を自動整合）。
     - カラー補間（sRGB / リニアRGB または HSL 補間）によるなめらかな混色。

### 既存ファイルの拡張
2. **`index.html`**:
   - `Displacement Map` セクションに隠しモード起動用の小さな `✦` トリガーボタン（`id="secret-texgen-trigger"`）を配置。
   - 隠しモード解禁時に表示される「🎨 テクスチャ生成 (Generator)」ボタン、または直接モーダルを開く機構。
   - テクスチャジェネレータ専用モーダル（`id="texgen-modal"`）：
     - リアルタイムプレビュー Canvas（自動縮小表示＋ズーム対応）。
     - 解像度入力（幅・高さpx）＋ φ80×100筒用（2513×1000px）を含むプリセットボタン。
     - 3色セレクター（色1、色2、色3）：
       - カラーピッカー ＋ プリセットパレット集（Amber Glow、Cyberpunk、Emerald、Monochrome等）。
       - 背景色の選択（ラジオボタン/トグルで色1, 2, 3から1色を背景、残り2色をグラデーション色に設定）。
     - パターン形状セレクター（丸、多角形、星型、ひし形等）。
     - 配列モードセレクター（垂直グラデーション、左右フュージョン、ウェーブ、放射状等）。
     - スライダー群（グリッド密度/列数、ドット最小/最大サイズ、コントラスト/変化幅、オフセット、回転角度）。
     - シームレス周回トグル、格子タイプ（千鳥 / 直交）トグル。
     - 「ランダム生成 (Random / 🎲)」ボタン。
     - 「モデルに適用 (Apply to Model)」ボタン。
     - 「PNG保存 (Download PNG)」ボタン。

3. **`style.css`**:
   - テクスチャジェネレータモーダルのダーク/ライトテーマ対応スタイリング。
   - グリッドレイアウト、カラーパレットスウォッチ、リッチなスライダーとコントロール。

4. **`js/main.js`**:
   - 隠しモード解禁のトリガー（ヘッダーダブルクリック、`✦`ボタンクリック、URLパラメータ `?texgen=1`）。
   - モーダル初期化、プレビューのリアルタイム更新（デバウンス付き）、モデルへの即時反映ロジック。
   - `activeMapEntry` への登録とビューア更新。

5. **`js/i18n/ja.js`, `js/i18n/en.js` 等**:
   - UIの多言語ラベル（日本語・英語）。

## 3. 開発および検証ステップ

1. **ステップ1: テクスチャ生成コアロジック (`js/textureGenerator.js`)**
   - パターン描画、配列計算、3色ブレンディング、シームレス周回計算を実装。
2. **ステップ2: モーダルUIとスタイリング (`index.html`, `style.css`)**
   - 直感的で操作性の高い設定パネルとリアルタイムプレビューを配置。
3. **ステップ3: イベント連携と隠しモード解禁 (`js/main.js`)**
   - パラメータ変更のリアルタイムプレビュー、モデルへのロード連携、PNG保存。
4. **ステップ4: ブラウザ実機テスト (Headless Browser Subagent)**
   - 隠しモード起動、添付画像パターンの再現、パラメータ変更、モデル反映の動作確認。
5. **ステップ5: ドキュメントまとめ (`walkthrough.md`)**
   - 使い方、各パラメータの効果、生成結果のまとめ。
6. **ステップ6: Git コミット・プッシュ & Vercel デプロイ反映**
   - `feature/procedural-texture-generator` をプッシュ、および Vercel へのアップロード/ブランチ反映。
7. **ステップ7: 3MFエクスポート多色変位反映 & 1層1色の完全保証 (v1.2.4)**
   - `js/version.js` を `1.2.4` に更新。
   - `js/main.js` の `sampleFn` で `computeMultiColorBlend` を導入し、白とオレンジの出っ張り反転を3MFエクスポート時にも完全適用。
   - `js/layerSlicing.js` の退化スライバー除外および棚面（Shelf Triangles）のツールを `botTool` に統一し、1層1色のルール崩壊（189層目に白の粒が混入する現象）を完全根絶。
   - 自動検証スクリプトによるゼロ違反（0 / 150層）の確認。
