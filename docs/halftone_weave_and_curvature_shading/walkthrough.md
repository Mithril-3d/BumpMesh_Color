# 実装完了・ウォークスルー: ハーフトーン編み重ね & 凹凸曲率シェーディング (v1.5.1)

## 1. はじめに

YouTube動画 **「Halftone 3D Printing: Smooth Gradients With Just 2 Colors!」**（https://www.youtube.com/watch?v=D2Vb8wZi7k4）で紹介された革新的なハーフトーン3Dプリント技術を、**BumpMesh_Color v1.5.1** として新ブランチ `feature/v1.5.1-halftone-weave` 上で完全実装・検証しました。

Blender のノード手作業や有償配布アドオン（Nozzleboss等）を必要とせず、**ブラウザ単体でSTL/OBJ/STEPモデルの読み込みから、幾何曲率陰影計算、正弦波編み重ね変調、WebGLリアルタイムプレビュー、そして水密なマルチツール3MFエクスポートまでを一気通貫で完結**できるパイプラインが完成しました。

## 2. 実装された2大新機能の概要

### ① 幾何学的凹凸・曲率シェーディングエンジン ([meshCurvature.js](file:///c:/Users/Vogler/Documents/3dprint/Antigravity/BumpMesh_Color/js/meshCurvature.js))
**「外部画像やUV展開が一切不要！立体モデル自身の凹凸から陰影を自動生成」**

- **アルゴリズム**:
  - メッシュの頂点を高速空間ハッシュで一意頂点に量子化集約。
  - 面積加重法線（Area-weighted Normals）と隣接トポロジーグラフを構築。
  - 重み付き近傍重心差ベクトル $L_u = c_u - p_u$ と頂点法線 $n_u$ の射影内積を計算し、平均曲率とキャビティ（窪み）/ リッジ（稜線）を正確に分離推定。
  - ラプラシアン拡散平滑化パス（Facet Smoothing）により、ローポリモデルや3Dスキャンデータのファセットノイズを除去。
  - 98パーセンタイルによるロバスト正規化で針状特異点の影響を排除し、コントラスト・バイアス・ガンマ・反転調整を経て [0.0, 1.0] の輝度場を出力。
- **実用的メリット**:
  - UVマップの展開が難しくテクスチャを綺麗に貼れなかった人の頭部、胸像、キャラクター、動物などの立体形状でも、読み込んで「モデル凹凸」を選ぶだけで即座に美しい陰影がつきます。

### ② 正弦波編み重ね・ハーフトーン変位エンジン ([layerBlending.js](file:///c:/Users/Vogler/Documents/3dprint/Antigravity/BumpMesh_Color/js/layerBlending.js))
**「ペリメータ1（外壁1周）でも崩れない交差トラス構造 ＆ 2色だけで滑らかな中間階調」**

- **アルゴリズム**:
  - 断面形状（遮蔽プロファイル）に `正弦波編み重ね (Sinusoidal Weave)` を新設。
  - 水平周回角度と円弧長に基づくサイン波変形（波長ピッチ、波の振幅）。
  - 層（Layer）ごとに 180° 位相シフト（`layerPhase = (layerIdx % 2) * PI`）を適用し、上下層の波を互い違いに交差編み込み。
  - 陰影（曲率またはテクスチャ）の露出比率 $ratio$ に応じて外側への突出オフセットと振幅を変調。白を出したい部分は白層の波が外に出て黒を遮蔽し、中間部では白と黒が均等に編み合わさって滑らかなグレーに見えます。
- **実用的メリット**:
  - 外壁1周（Wall Loops: 1）でも上下層が強固に噛み合い、積層剥離や崩れを防ぎます。
  - ツールチェンジ時のパージタワー・廃棄フィラメントが一切発生しないため、超高速かつエコに多色印刷が可能です。

## 3. UI・操作手順

1. **モデルの読み込み**:
   - 立体モデル（人の頭部や彫刻、凹凸のあるフィギュア等）をブラウザにドラッグ＆ドロップ。
2. **陰影ソースの選択**:
   - 右側パネルの「COLOR & MULTI-TOOL」で「交互積層 (振り重ね)」を有効化。
   - 新設された「陰影ソース」にて **「モデルの凹凸 (Mesh Curvature / UV不要)」** をクリック。
   - コントラスト、明るさバイアス、平滑化をお好みに合わせてスライダー調整。
3. **編み重ねハーフトーンの設定**:
   - 「断面形状（遮蔽）」で **「正弦波編み重ね (サイン波ハーフトーン・180°反転)」** を選択。
   - 「波長ピッチ (mm)」（推奨: 1.2〜2.0mm）と「波の振幅 (mm)」（推奨: 0.2〜0.35mm）を設定。
4. **プレビューとエクスポート**:
   - 3Dビューポート上で編み重ねの質感と陰影をリアルタイム確認。
   - **「3MFをエクスポート」** または **「Export Multi-Tool 3MF」** をクリックして水密マルチツール3MFを出力。

## 4. スライサー（Bambu Studio / OrcaSlicer / PrusaSlicer）での推奨印刷設定

動画（meditat氏）の手法を忠実に再現し、最も美しい仕上がりにするための推奨設定です：

| 設定項目 | 推奨値 | 理由 |
| :--- | :--- | :--- |
| **Wall Loops (壁ループ数)** | **1** | 正弦波編み重ねの外観を最大限引き立て、印刷時間を最短化 |
| **Detect Overhangs (オーバーハング検出)** | **OFF (無効)** | サイン波の微細な凹凸をオーバーハングと誤認して減速するのを防止 |
| **Seam Position (シーム位置)** | **背面 / ランダム** | 編み目の連続性を乱さない位置に配置 |
| **Layer Height (積層ピッチ)** | **0.20mm** (または 0.16mm) | BumpMesh_Colorの積層厚み設定と一致させる |
| **Infill (インフィル)** | **0%〜5%** (モデル形状による) | 花瓶・胸像なら中空またはジャイロイド数%で十分な強度 |
