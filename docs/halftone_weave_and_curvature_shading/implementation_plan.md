# 実装計画書: ハーフトーン編み重ね変位 & 幾何曲率シェーディング (Halftone Weave & Curvature Shading)

## 1. 概要 (Executive Summary)

本ドキュメントは、YouTube動画 **「Halftone 3D Printing: Smooth Gradients With Just 2 Colors!」** で実演されている最先端のマルチカラー3Dプリント技術を詳細に分析し、これを **BumpMesh_Color** に取り入れるための技術仕様、アーキテクチャ設計、および実装計画をまとめたものです。

本技術の核心は、**「わずか2色のフィラメント（例: 白と黒）を用い、ツール切り替えによるパージ（材料廃棄・時間ロス）を一切行わずに、積層パスの微細な波状変位（Displacement）によって滑らかな階調（ハーフトーン）を表現する」** ことにあります。さらに、**「人の頭部などの立体的な形状に対し、外部テクスチャ画像の代わりにモデル自身の幾何学的凹凸（曲率・キャビティ）から陰影を自動生成する」** アプローチを融合させることで、UV展開の歪みやテクスチャ貼りの困難さを根本から解消します。

## 2. 動画技術「Halftone 3D Printing」の技術的解剖

動画（およびNotebookLM要約）で紹介されている技術パイプラインは、以下の3つの物理・幾何学的要素から構成されています。

```
                     【動画のパイプライン】
                     
[3Dモデル (立体)] ───► [スライサー] ───► [ベースGコード生成 (層高一定)]
                                                 │
                                                 ▼
[曲率/テクスチャ] ───► [Blender: 幾何ノード] ◄── [外壁パスの細分割 (0.2mm)]
                                │
                                ▼
                   [ハーフトーン正弦波変調]
                   ・白/黒の層交代 (Interleaved)
                   ・正弦波の編み重ね (Weave)
                   ・振幅・突出比率の変調
                                │
              ┌─────────────────┴─────────────────┐
              ▼                                   ▼
    [Prusa XL等: Gコード直接出力]       [Bambu Studio等: STL + モディファイア]
```

### 2.1. 原理1: なぜ2色で滑らかなグラデーションができるのか？（ハーフトーン原理）
- **従来の多色プリントの弱点**: 1層の中で白から黒へグラデーションを作ろうとすると、ツール切替とパージが爆発的に増え、印刷時間が数十倍になり大量のフィラメントゴミが発生します。
- **1層おき交互積層 (Interleaved Slicing)**: 奇数層を白、偶数層を黒で印刷すれば、パージは一切不要（1層につき1回の切替のみ）です。
- **物理変位による面積変調（ハーフトーン）**:
  - 外壁の押し出しパスを法線方向にオフセット（突出・後退）させます。
  - **白を濃くしたい部分**: 白の層のパスを大きく外側に張り出させ、黒の層のパスを奥へ引っ込めます。外から見ると白が黒を物理的に遮蔽・ハイライトします。
  - **黒を濃くしたい部分**: 逆に黒の層を外側に張り出させ、白を引っ込めます。
  - **中間調（グレー）**: 白と黒が均等に露出し、人間の視覚には目の解像度限界によって2色の混色（50%グレー）として知覚されます。

### 2.2. 原理2: なぜ「正弦波のような編み重ね（Weave）」が必要なのか？
ユーザーの洞察の通り、**「ペリメータ1（外壁1周の薄肉造形）で崩れないようにするため」**、および **「露出の線状ノイズ（モアレ・層筋）を消すため」** に正弦波の編み重ねが不可欠です。

1. **トラス・インターロック構造による力学的剛性**:
   - 単に層全体を一様に内外へ押し出す（平坦なひさし構造）だけだと、上下層の接触面積が大幅に減少し、1周の薄い外壁では層間剥離（デラミネーション）を起こして破断・崩壊します。
   - 上下の層で位相を 180° 反転させた正弦波（$\sin(kx)$ と $\sin(kx + \pi) = -\sin(kx)$）状に変形させると、**上下の層が周期的に交差して物理的にしっかりと噛み合います（織物・トラス構造）**。これにより、外壁1周でも驚異的な剛性と自立安定性を発揮します。
2. **連続的な視覚的混色（網点化）**:
   - 正弦波の振幅（波の高さ）とオフセットを変化させることで、表面に微細な編み目（Weave pattern）が形成され、ドット状・ライン状のハーフトーンスクリーン効果が生まれ、層ごとのストライプ感が消えて自然な陰影に見えます。

### 2.3. 原理3: なぜ「凹凸に従って白黒を入れる機能」が必要なのか？
- **テクスチャ投影の限界**:
  - 人の顔、胸像、クリーチャー、有機的スカルプトなどの複雑な3D形状にテクスチャ画像を貼ろうとすると、平面投影・円筒投影では耳の裏、顎の下、目のくぼみ、鼻の側面で極端な引き伸ばし（テクスチャストレッチ）や継ぎ目（シーム）が発生します。
  - UVアンラップ（展開）を行うには専用のDCCツール（Blender等）が必要で、Webブラウザ単体で手軽に行うのは困難です。
- **幾何学的凹凸（曲率・キャビティ）からの直接シェーディング**:
  - モデル自身のメッシュ形状から、**「凸部（Ridge: 鼻先、頬、額など）＝ 明るい（白）」**、**「凹部（Valley/Crevice: 目のくぼみ、小鼻の脇、耳の溝、口元など）＝ 暗い（黒）」** というスカラー場を自動計算すれば、**外部画像もUV展開も一切不要**で、モデルの立体美を強調する完璧な陰影（シェーディング）が得られます。

                             ├─ 水平正弦波変調: sin(kθ + L・π)
                             └─ 輝度 I による振幅・露出オフセット変調

### 4.1. 機能1: 幾何学的凹凸・曲率シェーディングエンジン (`js/meshCurvature.js`) 【新規】
- **役割**: 外部テクスチャに依存せず、メッシュ自身の立体形状の凹凸（曲率や溝）から 0.0〜1.0 の輝度値（スカラー場）を各頂点に自動付与する。
- **実装場所**: 新規ファイル `js/meshCurvature.js`
- **使用アルゴリズム**:
  - `meshTuring.js` で実績のある **コタンジェント重み付きラプラス・ベルトラミ演算子（Discrete Cotangent Laplace-Beltrami Operator）** を再利用。
  - 各頂点 $i$ の位置ベクトル $\vec{x}_i$ に対して、ラプラシアン $\Delta \vec{x}_i$ を計算。
  - 微分幾何学の基本定理より、$\Delta \vec{x}_i = -2 H_i \vec{n}_i$（$H_i$ は平均曲率、$\vec{n}_i$ は頂点法線）。
  - 法線との内積 $\Delta \vec{x}_i \cdot \vec{n}_i$ を取ることで、**「凸部（正）か凹部（負）か」** の符号と強度を直接取得。
  - **パラメータ**:
    - `Curvature Contrast`: コントラスト調整（ガンマ・S字カーブ）
    - `Curvature Bias`: 明るさの全体オフセット
    - `Invert Shading`: 凸を黒・凹を白にする反転トグル
    - `Smoothing Iterations`: 局所ノイズを除去するラプラシアン平滑化ステップ数

### 4.2. 機能2: 正弦波編み重ね・ハーフトーン変位エンジン (`js/layerBlending.js` / `js/displacement.js`) 【拡張】
- **役割**: 交互積層（Interleaved）のプロファイルに、水平方向の正弦波（サイン波）を掛け合わせ、層間で位相を反転させた編み重ねジオメトリを生成する。
- **実装場所**: `js/layerBlending.js` の `computeLouverDisplacement` を拡張、または `computeHalftoneWeaveDisplacement` を新設。
- **数式モデル**:
  - 各頂点の高さ $z$ から層インデックス $L = \lfloor (z - z_{min}) / t \rfloor$ を算出。
  - 頂点の水平位置から周回位相角 $\theta = \text{atan2}(y - c_y, x - c_x)$ または水平弧長 $s$ を算出。
  - 水平周波数 $f$（波長 $\lambda$）と層ごとの位相シフト $\Delta \phi = \pi$（180度反転）によるサイン波:
    $$W(x, y, L) = \sin(2\pi f \cdot \text{dist} + L \cdot \pi)$$
  - 輝度値 $I \in [0, 1]$（曲率またはテクスチャ明度）に基づく変位量:
    - **白ツール層（例: 偶数層）**:
      $$\text{Disp}_{white} = A_{base} + A_{wave} \cdot \left( I \cdot (1 + W) - 1 \right)$$
    - **黒ツール層（例: 奇数層）**:
      $$\text{Disp}_{black} = A_{base} + A_{wave} \cdot \left( (1 - I) \cdot (1 - W) - 1 \right)$$
  - これにより、$I \approx 1$（白領域）では白層が外側に張り出し波の山が露出、$I \approx 0$（黒領域）では黒層が張り出し、中間部では白と黒の波が互い違いに噛み合いながら半分ずつ露出する。

### 4.3. 機能3: リアルタイムWebGLシェーダープレビュー (`js/previewMaterial.js`) 【拡張】
- **役割**: 3Dビューポート上で、重いメッシュ再構築を待つことなく、スライダーを動かした瞬間にハーフトーン編み重ねと曲率シェーディングの陰影がリアルタイムに見えるようにする。
- **実装場所**: `js/previewMaterial.js` の頂点シェーダーおよびフラグメントシェーダー
- **処理**:
  - バーテックスシェーダー内で上記の $W(x, y, L)$ と輝度 $I$ による頂点変位をGPU計算。
  - フラグメントシェーダー内で、層ごとのツールカラー（Tool 1 / Tool 2）と変位面のライティングを描画。

### 4.4. 機能4: UI・コントローラーの統合 (`index.html`, `js/main.js`) 【拡張】
- **役割**: ユーザーが「テクスチャ画像を使う」か「モデルの凹凸（曲率）を使う」かをワンクリックで選べ、編み重ねパラメータを微調整できる直感的なUI。
- **追加UI要素**:
  1. **Shading Source (陰影ソース)** セレクトボックス:
     - `Texture Map (テクスチャ画像)`（既存）
     - `Mesh Curvature / Cavity (モデル凹凸曲率)`（★新規）
     - `Hybrid (曲率 + テクスチャ合成)`（★新規）
  2. **Interleaved Profile Mode**:
     - `0: Flat Step (従来の平坦ステップ)`
     - `1: 45° Louver (ひさし型)`
     - `2: Sinusoidal Weave (★正弦波編み重ねハーフトーン)`
  3. **Weave パラメータスライダー**:
     - `Wave Pitch (波のピッチ/波長)`: 0.5mm 〜 5.0mm (推奨: 1.5mm〜2.0mm)
     - `Wave Amplitude (波の振幅)`: 0.1mm 〜 0.8mm (推奨: 0.35mm)
     - `Layer Phase Offset (層間位相差)`: 180° (交互トラス) / 90° (斜め織り)

### 4.5. 機能5: 水密マルチツール3MFエクスポート連携 (`js/layerSlicing.js`) 【既存連携】
- **役割**: 変調後のメッシュを、Bambu Studio / PrusaSlicer がそのまま解釈できる水密なマルチツール3MFファイルに出力する。
- **ポイント**: BumpMesh_Colorの既存の `layerSlicing.js` は、頂点が変位した後のジオメトリを忠実に層ごとにスライスして Tool 1 と Tool 2 の独立したボリューム（Object Volume）として出力する能力をすでに持っています。そのため、変位エンジン側で正弦波編み重ねが適用されていれば、**既存のスライス・3MFエクスポートパイプラインをそのまま通過させるだけで、追加のプラグインなしにスライサー対応が完了**します。

## 5. アルゴリズムと数理モデル

### 5.1. 離散コタンジェント・ラプラシアンによる平均曲率の算出
三角形メッシュ $M = (V, F)$ 上のユニーク頂点 $i \in V$ に対し、隣接頂点 $j \in N(i)$ との間のコタンジェント重み $w_{ij}$ は以下のように計算されます：

$$w_{ij} = \frac{\cot \alpha_{ij} + \cot \beta_{ij}}{2}$$

頂点 $i$ のボロノイ双対面積（または重心面積）を $A_i$ とすると、離散ラプラス・ベルトラミ作用素は：

$$\Delta \vec{x}_i = \frac{1}{A_i} \sum_{j \in N(i)} w_{ij} (\vec{x}_j - \vec{x}_i)$$

このとき、平均曲率 $H_i$ と外向き単位法線 $\vec{n}_i$ には以下の関係が成り立ちます：

$$\Delta \vec{x}_i = - 2 H_i \vec{n}_i$$

したがって、符号付き平均曲率（凹凸スカラー値）$C_i$ は以下で求められます：

$$C_i = - \frac{1}{2} (\Delta \vec{x}_i \cdot \vec{n}_i)$$

- $C_i > 0$: **凸部 (Ridge)** → 白（Tool 1）にバイアス
- $C_i < 0$: **凹部 (Valley/Crevice)** → 黒（Tool 2）にバイアス
- $C_i \approx 0$: **平坦部 (Flat)** → 中間グレー（50%編み重ね）

これを正規化し、トーンカーブ関数（Smoothstep または Gamma）を通すことで、各頂点の輝度 $I_i \in [0, 1]$ が得られます。

## 6. スライサー側（Bambu Studio / PrusaSlicer）での印刷設定要件

動画で強調されているスライサー設定上の重要なポイントを、BumpMesh_Colorの出力仕様と合わせて標準化します。

1. **層高（Layer Height）の一貫性**:
   - 初層（First Layer Height）と通常層の層高を同一（例: 0.20mm、動画では太ノズルの場合0.6mm）に設定する。
   - ※BumpMesh_Colorの「Interleaved Thickness」とスライサーの層高を完全に一致させます。
2. **オーバーハング検出（Detect Overhangs）の無効化**:
   - 外壁の波状変位がオーバーハング扱いされて速度や流量が勝手に変調されるのを防ぐため、スライサーの「Detect Overhangs」をOFFにする。
3. **シーム位置（Seam Position）**:
   - 「背面（Back）」または「ペイントによる非表示面」に固定し、波状パターンの途中にシーム突起が散らばるのを防ぐ。
4. **シングルペリメータ（1壁）プリント**:
   - 壁ループ数（Wall Loops）を 1 に設定することで、高速かつ超軽量に編み重ねハーフトーンが完成する。

## 7. メリット・デメリットと技術的課題の対策

| 項目 | メリット | 潜在的な課題 | 解決策 |
| :--- | :--- | :--- | :--- |
| **凹凸シェーディング** | UV展開・画像不要。人の顔や彫刻の凹凸に完璧に沿った陰影が即座に出る | メッシュのポリゴン密度が粗いと曲率計算がノイズになる | 既存の `subdivide()`（細分割）およびラプラシアン平滑化フィルタを前処理として適用 |
| **正弦波編み重ね** | 1壁でも上下が噛み合い頑丈。パージなしで滑らかな2色グラデーション | メッシュの水平方向の位相が不均一（円筒座標でない自由曲面） | 3D空間のトリプラナー座標系または表面測地線に沿った等ピッチ波長生成 |
| **スライサー互換性** | 水密3MF出力によりBambu/Prusa両対応 | ポリゴン数が多くなると3MFファイルサイズが肥大化 | 既存の `decimate()`（スマートポリゴン削減）を外壁ディスプレイスメント後に適用 |
