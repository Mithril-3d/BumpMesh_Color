🎨 Automatic Ink-Shading (Panel-Lining) for Multi-Color 3D Printing

I added an automatic geometric ink-shading (panel-lining / 墨入れ) feature to BumpMesh_Color, an open-source multi-color 3D printing web tool! It adds deep physical relief and shadow contrast to sculptures and organic models—without needing any texture images or manual painting.

This Suzanne model is a demonstration sliced using this new feature for the ColorMix Contest.

🚀 Free Web App (Runs 100% locally in your browser)

The tool is publicly available for free (no installation required; everything runs locally on your computer):
👉 Web App: https://mithril-3d.github.io/BumpMesh_Color/
(Open-source repository on GitHub)

💡 How It Works

  1. Drop any 3D model (STL/OBJ/3MF/STEP) into the web tool.
  2. The engine mathematically computes the mean surface curvature of the 3D mesh.
  3. Convex peaks (highlights) and concave crevices (shadows) are automatically translated into alternating dual-tool layers (interleaved layers / 振り重ね).
  4. Export as a ready-to-print multi-part 3MF for PrusaSlicer, OrcaSlicer, or Bambu Studio!

🖨️ Recommended Slicer Settings (for the attached 3MF)

  • Infill: 0%
  • Top solid layers: 0
  • Perimeters (Walls): 1 or 2 (2 walls recommended for strong hollow prints)
  • Ensure vertical shell thickness: Disabled (Off)

彫刻やフィギュアなどの3Dモデルの凹凸から自動的に陰影を抽出し、墨入れしたかのようなメリハリのある立体マルチカラー造形ができる機能を、Webツール BumpMesh_Color に新機能として追加・実装しました。
