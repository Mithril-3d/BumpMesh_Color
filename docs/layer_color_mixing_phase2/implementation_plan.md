# 実装計画: 【Phase 2】交互積層（インターリーブ）によるマルチツール振り重ね積層

## 1. 仕様概要
- **対象色**: Phase 1 の「カラー量子化」で抽出された代表色（Tool 1..K）をそのまま使用（不要な混色プリセットは全廃）。
- **交互積層構造**:
  - 指定した一定の積層厚み $t$（例: 0.20mm）ごとに、各ツール（例: Tool 1 白 / Tool 2 赤）の層が交互に積み重なる。
  - レイヤー番号 $m = \lfloor z / t \rfloor$ に対し、アクティブツールは $T_{layer}(m) = (m \bmod K) + 1$。
- **局所的な凸凹（突出／引っ込み）反転**:
  - テクスチャ画像のその位置における目的色を $T_{target}(u, v)$ とする。
  - **目的色と一致する場合 ($T_{layer}(m) == T_{target}$)**:
    その層のモデルを外側へ「**凸**（突出, 例: +0.3mm）」にする。
  - **目的色と一致しない場合 ($T_{layer}(m) \ne T_{target}$)**:
    その層のモデルを内側へ「**凹**（引っ込む, 例: -0.1mm または 0mm）」にする。
  - これにより、白領域では白層が凸で表面に露出し、赤層は凹で隠れる。逆に赤領域では赤層が凸で表面に露出し、白層は凹で隠れる。
- **出力形式**:
  - 各ツールごとの輪切り層をまとめたマルチボリューム（マルチパーツ）の 3MF ファイルとして出力。スライサーで開いた際に各パーツにツールが割り当てられ、スライス時に自動でレイヤー交互積層が実行される。

---

## 2. 変更対象ファイルと詳細設計

### 1. `js/layerBlending.js`
- HueForge 関連の混色プリセットや複雑な光吸収式を撤廃。
- 交互積層アルゴリズムを実装：
  - `getLayerIndex(z, layerThickness)`
  - `getInterleavedTool(layerIndex, totalTools)`
  - `computeInterleavedDisplacement(u, v, z, targetTool, layerThickness, convexAmp, concaveAmp, totalTools)`:
    - レイヤー判定と目的色判定から、凸量または凹量を計算。

### 2. `index.html` & `style.css`
- 不要な「混色プリセット」「透過度(TD)」などのUIを完全撤去。
- シンプルで明確な「交互積層（振り重ね）設定」に刷新：
  - レイヤー積層厚み（mm、デフォルト 0.20mm）
  - 凸量（突出量 mm、デフォルト 0.30mm）
  - 凹量（引っ込み量 mm、デフォルト 0.00mm）
  - 現在のカラー量子化パレット（Tool 1..K）のプレビュー表示

### 3. `js/previewMaterial.js`
- シェーダー内で、Z高さに応じたレイヤー番号 $m = \lfloor z / t \rfloor$ と、テクスチャのターゲットツールを比較し、
  - 表面の凸凹（ディスプレイスメント）と、
  - 最表面に露出しているツールの色（凸になっているツールの色）
  をリアルタイムに3D描画。

### 4. `js/exporter.js` & `js/main.js`
- 3MF のマルチオブジェクト（Tool 1 用パーツ、Tool 2 用パーツ...）出力の実装。
- 各ツールごとに、該当レイヤー帯のメッシュ（または TriangleSelector / マルチコンポーネント）をパック。
- PrusaSlicer / Bambu Studio で各パーツが正しいツールに割り当てられて開くことを保証。

## 3. 検証計画
1. **アルゴリズムテスト (Node.js)**:
   - 白地に赤丸のテスト画像・モデルに対し、白領域で白が凸・赤が凹、赤領域で赤が凸・白が凹になっているか検証。
2. **PrusaSlicer CLI でのスライス検証**:
   - 生成したマルチボリューム 3MF を PrusaSlicer CLI でスライスし、レイヤーごとに白と赤が交互にツールチェンジされ、各領域の外壁が正しく目的色で出力されるか G-code を検証。
