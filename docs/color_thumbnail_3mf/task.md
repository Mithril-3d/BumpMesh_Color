# タスク: 3MFマルチカラーエクスポート時のサムネイルカラー化

## 概要
3MFファイル内に埋め込まれるサムネイル画像（PrusaSlicer, Bambu Studio, OrcaSlicer, Windowsエクスプローラー等で表示されるプレビュー画像）が、現在はビューワーのデフォルト状態（グレー）のままキャプチャされているため、マルチカラー設定したパレット色が反映されていません。
エクスポート時に決定される各三角形のツールID（`triTools`）とBumpMesh_Colorで設定されたパレット色（`exportPalette`）を用いて、正確に着色された3Dプレビューサムネイルを生成・埋め込みます。
