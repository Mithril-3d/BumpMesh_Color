# タスクリスト: 編み重ね専用・断面四角の輪ゴム積層チューブ生成 (Weave Rubber Band Tube)

## 概要
編み重ね（Weave: 矩形ブロック・三角波・正弦波）選択時限定で、中実メッシュのスライス・変位方式から脱却し、各レイヤーが断面四角の均一肉厚（デフォルト 0.4mm）の輪ゴム（帯状リング）として上下に水密マージされた中空チューブ構造を直接生成・エクスポートするパイプラインを実装する。
