# 交互積層（振り重ね）フラット段差標準化 実装完了レポート

## 1. 概要
交互積層（マルチツール振り重ね）モードにおいて、直線部分やフラットな領域に発生していたモコモコ・ブツブツとした細かい波打ち・ジグザグノイズを解消するため、断面形状の標準を「フラット段差（標準ステップ・推奨）」に変更し、3Dプレビュー・計算パイプライン・エクスポート全体の初期値と変位処理を最適化しました。

これにより、参考作品（3枚目の画像）のように、平坦な面や直線・円弧が完全にフラットで滑らかなステップとしてスライス・印刷できるようになりました。

---

## 2. 根本原因の特定と対策

### 原因
- 設定画面で「45° ルーバー庇（他色シールド）」が選択されていた場合、厚み0.20mmの1層の中で頂点のZ高さに応じて突出量を0.10mm〜0.30mmへと傾斜させようとします。
- しかし、三角形メッシュの頂点はZ方向にランダムにばらついているため、同じ平坦な面にある頂点同士であっても突出量がランダムに乱高下し、スライサーで切断されたときに周期的な波打ち・ジグザグになっていました。

### 対策
- 3枚目の参考作品およびFDM 3Dプリントの実証通り、0.2〜0.3mm程度のオーバーハングであれば45度の庇がなくても完璧に積層できるため、**「フラット段差（標準ステップ・推奨）」** を標準化しました。
- フラット段差モード時、各層の内部にある頂点は層の高さ全体で完全に均一な突出量（グラデーション比率に応じた一定値）を受け取るため、Z方向の傾斜や頂点のばらつきによるジグザグがゼロになります。

---

## 3. 変更内容

1. **UIの更新 (`index.html`)**:
   - `interleaved-profile-mode` セレクタのデフォルト値を `0`（フラット段差・推奨）に変更。
   - 選択肢表示を「フラット段差（標準ステップ・推奨）」および「45° ルーバー庇（他色シールド・実験的）」に更新。
   - ツールチップを「層ごとの断面形状。フラット段差は直線が美しく、他作品のような綺麗な仕上がりになる標準方式です。」に更新。

2. **アプリ設定・イベント管理 (`js/main.js`)**:
   - `interleavedSettings.profileMode` の初期値を `0` に変更。
   - 情報テキスト（`interleavedInfoText`）の表示を「フラット段差（標準ステップ・推奨）」に更新。
   - エクスポート時およびプレビュー更新時のフォールバック値をすべて `0`（フラット段差）に統一。

3. **変位計算コアロジック (`js/layerBlending.js`, `js/displacement.js`)**:
   - `computeLouverDisplacement` のデフォルト引数を `profileMode = 0` に変更。
   - `displacement.js` 内でのフォールバック値を `0` に更新。

4. **3Dプレビューシェーダー (`js/previewMaterial.js`)**:
   - `interleavedProfileMode` uniform をシェーダーに追加。
   - フラット段差モード選択時は、3Dビュー上でもスロープ傾斜を入れず、完全なフラットステップとしてプレビュー表示されるよう同期。

## 4. 検証結果

### 均一性テスト (`scratch/test_flat_step_export.mjs`):
- **凸層（Layer 1: 0.20mm〜0.40mm）**:
  - `z = 0.201mm`: 0.3000mm
  - `z = 0.300mm`: 0.3000mm
  - `z = 0.399mm`: 0.3000mm
  - 層の全域で変位は **0.3000mm 均一（分散 0.0000）**。
- **凹層（Layer 0: 0.00mm〜0.20mm）**:
  - 層の全域で変位は **0.0000mm 均一（分散 0.0000）**。
- 45°ルーバー庇で生じていた 0.10mm〜0.30mm のランダムな乱高下・波打ちが完全に排除され、直線部分が数学的に完全なフラットになることを確認。

## 5. UI改善: エクスポートボタンの常時固定表示（Sticky Footer）

### 概要
設定パネルが縦に長くなった際、エクスポートを行うために毎回最下部までスクロールする必要があった問題を解消するため、サイドパネル下部にエクスポート操作エリアを常時固定表示するSticky Footerを実装しました。

### 実装内容
- **Flexbox分割レイアウト (`index.html`, `style.css`)**:
  - `#settings-panel` を縦方向のFlexコンテナ化。
  - 上部設定項目群を `.settings-scroll-content` 内で独立スクロール化。
  - 最下部に `.export-sticky-footer` を配置し、プログレスバーおよび各種エクスポートボタン（Export STL / Export 3MF / 🎨 Export Multi-Tool 3MF）を常時固定表示。
  - 上段に「Export STL」「Export 3MF」を並列配置し、下段に「Export Multi-Tool 3MF」をフルワイド配置。
  - パネルのどこをスクロールして設定を調整していても、常にワンクリックでエクスポートを開始できるよう利便性を向上。
