# 交互積層マルチツール振り重ねにおける無段階カラーグラデーション機能の実装計画

## 概要
従来の「交互積層（振り重ね）」は、テクスチャを減色して特定ツールに一致するか否か（0または1）の二値で出っ張り／引っ込みを判定していました。
本計画では、元画像の階調（256階調の無段階アナログ値）に準拠し、**各層の突き出し量（出っ張り量）をピクセルの色比率に応じて0.00mm〜0.35mmの間で連続的に制御する「グラデーション（連続階調）」モード**を追加します。

これにより、2つの単色フィラメント（例: 白と黒）だけで、中間のグレーや滑らかな階調変化を物理的に実体化できるようになります。

---

## 提案する変更内容

### 1. コアロジック: 色補間比率と連続変位の計算 (`js/layerBlending.js`)
- `computeColorBlendWeight(rgb, colorA, colorB)`:
  - 元画像のRGB値 $(R, G, B)$ が、選択パレットの2色（$C_A, C_B$）の間でどの位置にあるか（$0.0 \sim 1.0$）をRGB色空間の線形射影により高速計算。
- `computeLouverDisplacement` の拡張:
  - 引数に `blendWeight`（$0.0 \sim 1.0$）と `shadingMode`（0: ステップ, 1: グラデーション）を追加。
  - `shadingMode === 1` の場合：
    - 偶数層（Tool A）の突き出し量上限：$convexAmp \times blendWeight$
    - 奇数層（Tool B）の突き出し量上限：$convexAmp \times (1.0 - blendWeight)$
    - ルーバー庇（45°）およびフラット段差の両方で、この連続量に応じたスロープと変位量を計算。

### 2. UIの追加 (`index.html`, `style.css`, `js/main.js`)
- 「交互積層」設定欄に「階調表現モード」セレクトボックスを追加：
  - **シャープ (二値 / 0-1)** [デフォルト]: ロゴやくっきりした模様向け
  - **グラデーション (連続階調)**: 写真やグラデーション画像向け
- ユーザー設定の `interleavedSettings.shadingMode` として永続化。

### 3. 変位パイプラインへの統合 (`js/displacement.js`)
- `applyDisplacement` 内で、テクスチャから元カラーRGBをサンプリングし、`blendWeight` を算出。
- `computeLouverDisplacement` に渡して各頂点の変位量を滑らかに連続生成。

### 4. 3Dプレビューシェーダーの拡張 (`js/previewMaterial.js`)
- プレビューでも、グラデーションモード時に実物と同じように中間色が混ざり合って見えるようシェーダー（バーテックス・フラグメント）を更新。

## 検証計画

### 1. ユニットテスト
- 白黒グラデーション、カラーグラデーションにおける `blendWeight` の連続性・境界値テスト。
- 変位量が出っ張り0.00mm〜0.35mmの間で線形に滑らかに計算されることの確認。

### 2. 統合テスト & スライサー検証
- グラデーション画像を貼り付けたキューブを生成。
- 3MFをエクスポートし、PrusaSlicerでスライス。
- G-codeのペリメーター（輪郭）座標を解析し、外周の突き出し量が滑らかにカーブを描いていることを検証。
