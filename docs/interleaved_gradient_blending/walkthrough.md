# 交互積層（マルチツール振り重ね）無段階カラーグラデーション機能 実装完了レポート

## 1. 概要
交互積層（マルチツール振り重ね）モードにおいて、元画像の階調（256階調以上の連続階調）を忠実に反映して、2色の露出比率（はみ出し量）を無段階に制御する「カラーグラデーション（連続階調）」機能を実装しました。

これまでの「シャープ（二値）」モード（目的色に完全に一致した層だけを最大突出させる方式）に加え、ドロップダウンから「グラデーション（連続階調）」を選択できるようになりました。

---

## 2. 変更・実装内容

### (1) コア計算ロジック (`js/layerBlending.js`)
- **`computeColorBlendWeight(rgb, colorA, colorB)` の追加**:
  - サンプリングしたピクセルカラーを、第1ツール色（colorA）と第2ツール色（colorB）を結ぶRGB空間の線分上に射影し、連続的な混合比率（重み: 0.0〜1.0）を計算します。
- **`computeLouverDisplacement` の拡張**:
  - `shadingMode`（0: シャープ / 1: グラデーション）および `blendWeight` 引数を追加。
  - グラデーションモード（shadingMode = 1）時:
    - 偶数層（Tool 1担当）の最大突出量: `0.35mm × 重み`
    - 奇数層（Tool 2担当）の最大突出量: `0.35mm × (1.0 - 重み)`
    - 45°ルーバー庇のスロープも突出量に合わせて自動スケーリングされるため、オーバーハング角度（45度以下）の安全性が完全に保たれます。

### (2) UIの追加 (`index.html`, `js/main.js`)
- 「交互積層（振り重ね）」設定パネルに「階調表現」セレクタを追加:
  - **シャープ (二値 / 0-1)**: 従来通り、各層が完全突出（0.35mm）または完全引込（0.00mm）。
  - **グラデーション (連続階調)**: 元画像の色比率に応じた無段階突出。
- プリセット値（凸突出量 +0.35mm、凹引込量 0.00mm、断面 45°ルーバー庇）と連動し、リアルタイムに情報テキストへ反映。

### (3) 変位パイプライン・エクスポート・プレビューの統合 (`js/displacement.js`, `js/previewMaterial.js`)
- **`sampleRGBBilinear` 関数の追加**:
  - メッシュ変位計算時にバイリニア補間でRGB値を滑らかにサンプリング。
- **3Dプレビューシェーダーの更新**:
  - `interleavedShadingMode` uniform を追加し、3Dキャンバス上でもグラデーションによる肉厚変化と層の露出度合いを正確にリアルタイム描画。
- **エクスポート/ベイクパイプラインへの連携**:
  - `effectiveSettings` に `interleavedShadingMode` を引き継ぎ、マルチツール3MFエクスポート時にも各層が「1層1色」を維持したまま、ペリメーターの肉厚（突き出し量）が無段階に変化して出力されます。

## 3. 検証結果

### 自動テストスクリプト (`scratch/test_gradation_continuity.mjs`) の実行結果:
- **重み計算テスト**:
  - 白色 (255, 255, 255) → 重み 1.0 (PASS)
  - 黒色 (0, 0, 0) → 重み 0.0 (PASS)
  - 中間グレー (128, 128, 128) → 重み 0.5020 (PASS)
- **256階調連続性・単調性テスト**:
  - 偶数層（Tool 1）: 黒(0)の 0.0000mm から 白(255)の 0.3500mm まで、256ステップにわたり**単調増加かつ滑らかに無段階変化**することを確認。
  - 奇数層（Tool 2）: 黒(0)の 0.3500mm から 白(255)の 0.0000mm まで、256ステップにわたり**単調減少かつ滑らかに無段階変化**することを確認。
  - 中間グレー (128) では両層とも約 0.175mm（0.35mmのちょうど半分）ずつ均等に露出し、理想的な50%混色が物理的に形成されることを確認。
