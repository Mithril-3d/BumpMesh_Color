# 実装ウォークスルー: 三角波編み重ね（ジグザグ方式）と解像度最適化

## 1. 概要
従来の正弦波編み重ねにおいて生じていた**「ナイキスト限界の割り込み（1波あたり0.82頂点）によるモアレ崩れ」**および**「変位ロジックの早期リターンによる片方層の波平坦化バグ」**を解消し、軽量かつFDMスライスに最適な**「📐 三角波編み重ね（ジグザグ方式）」**を実装しました。

---

## 2. 変更内容一覧

### ① 三角波（Zigzag Wave）プロファイルの追加
- **数式モデル**:
  1周の周期 $2\pi$ に対する正規化位相 $u \in [0, 1)$ から、1次区分線形関数によって完全な三角波 $W \in [-1, 1]$ を生成。
  $$u = \text{mod}\left(\frac{\phi}{2\pi}, 1.0\right)$$
  $$W = 1.0 - 4.0 \cdot \left| u - 0.5 \right|$$
  - サインカーブの滑らかな近似に多量の頂点を費やすことなく、**1波あたり山と谷の2〜3点のみ**でクリーンなジグザグ形状を形成。
  - ノズルが連続した折れ線ループを一筆書きで高速走査可能（スリットのようなパス分断やリトラクションの連発が起きない）。

### ② 白黒シーソー逆位相変位への刷新（バグ修正）
- **修正前**:
  ブレンド比率 $ratio \le 0.0$ の早期リターンが存在したため、白が優勢な領域では茶色層が波打たずに平坦（突出量0mm）になり、逆位相の噛み合いが失われていた。
- **修正後**:
  アクティブ層の担当ツール（Tool 1 / Tool 2）に応じて、明度比率から露出度 $\text{exposure} \in [0, 1]$ を計算。
  $$\text{dcOffset} = -\text{concaveVal} + (\text{convexVal} + \text{concaveVal}) \cdot \text{exposure}$$
  $$\text{modFactor} = 2.0 \cdot \min(\text{exposure}, 1.0 - \text{exposure})$$
  $$\text{disp} = \text{dcOffset} + \text{waveAmp} \cdot W \cdot \text{modFactor}$$
  - 中間色（$0.5$）では白層と黒層が**完全に同じ振幅で逆位相に噛み合う**。
  - 純白・純黒に近づくにつれて波が自然に平坦な外壁へと収束する。

### ③ シリンダー初期解像度（周方向分割数）の最適化
- 従来の固定 `128` 分割（頂点間隔 約1.96mm ＞ 波長1.60mm）を、**`384` 分割（頂点間隔 約0.65mm）** に引き上げ。
- 1波（1.60mm）あたり約 2.5 頂点が確保され、**ナイキスト限界（$\ge 2$ 点/波）を完全にクリア**。
- 三角形数は約8万枚（ファイルサイズ約4MB）と極めて軽量で、スライサーの読み込みとスライスが軽快に動作。

### ④ UI・多言語リソースの更新
- 「断面形状（遮蔽）」セレクトボックスに **「📐 三角波編み重ね（ジグザグ・軽量高速・推奨）」**（`value="3"`）を追加。
- 3Dプレビュー（GPU頂点・フラグメントシェーダー）と3MFエクスポート（CPUスライス変位）の完全同期。

### ⑤ 🧱 矩形ブロック編み重ね（ひぃちゃん方式）の新設
- **原理と成功例の分析**:
  3Dプリンタのノズルは、メッシュが四角いブロックであっても、ノズル先端の丸みや溶融樹脂の表面張力によって、**自然に綺麗な丸いモコモコ（プリプリビード）に成形**されます。
- **数式モデル（台形ブロックパルス）**:
  デューティ比50%の矩形波に対して、スライサーの自己交差を防ぐ5%の微小スロープを持つ台形波を生成。
  - $u < 0.5$ の区間で $+1.0$（突出ブロック）、$u \ge 0.5$ の区間で $-1.0$（引っ込みブロック）。
- **振幅・突出量の上限引き上げ**:
  - 0.4mmノズルの線幅（約0.45mm）に対して、従来の振幅0.2mmは小さすぎて樹脂に埋没していたため、**凸量（突出量）を最大3.0mm（推奨0.8〜1.2mm）、波の振幅を最大2.5mm（推奨0.6〜1.0mm）**に大幅拡張。
  - ノズルが外側に大きく振れることで、下層の奥にある色が外から見えるようになり、写真通りのハッキリとしたハーフトーン編み重ねが実現。

## 3. 推奨スライサー設定（PrusaSlicer / Bambu Studio）

本方式で印刷する際は、スライサー側で以下の設定を行ってください。

| 設定項目 | 推奨値 | 理由 |
| :--- | :--- | :--- |
| **境界線（Perimeters / 壁ループ数）** | **1** | 【絶対必須】外壁を1本の連続ループで描画するため（2本以上だと内側で潰れる） |
| **スパイラル花瓶（Spiral Vase）** | **OFF** | 2色交互層プリントのためOFF。代わりにインフィル0%・トップ0で中空にする |
| **インフィル** | **0%** | 内側の不要なシェルパスによる外壁干渉を防止 |
| **トップレイヤー** | **0** | 上部を塞がず中空にする（花瓶構造） |
| **スライス解像度 (Resolution)** | **0** または **0.005** | 【重要】微細なブロックや波をスライサーがゴミと誤認して直線に丸めるのを防止 |
| **薄壁を検知 (Detect thin walls)** | **OFF** | 突出した突起が薄壁判定されてパスが乱れるのを防止 |
| **オーバーハング検出** | **OFF** | 突起をオーバーハングと誤認して減速・線幅変更するのを防止 |
| **積層ピッチ** | **0.20mm** | BumpMesh_Colorの「積層厚み (0.20mm)」と一致させる |
