# 実装計画: 編み重ね専用・断面四角の輪ゴム積層チューブ生成 (Weave Rubber Band Tube)

## 1. 背景と課題

### 現状の問題点
- 従来の編み重ね（Weave）出力は、中実モデル（中身の詰まった円柱など）をレイヤー境界で切断し、既存メッシュの頂点を後から動かす「ディスプレイスメント方式」を採用していた。
- **課題1（サンプリング破綻 / エイリアシング）**:
  - メッシュの周方向ポリゴン解像度（0.65mm〜0.85mm）に対して、矩形ブロック波の半周期幅（0.80mm）や立ち上がり幅（0.08mm）が細かすぎるため、ブロックの角（立ち上がり）に頂点が配置されず、ランダムな砂利・毛羽立ち・トゲトゲノイズになっていた。
- **課題2（中実モデルに起因するスリット露出とソリッドインフィル誤認）**:
  - 中実モデルのため、白100%の領域でも奥に引っ込んだ茶色の層が溝（スリット）として露出し、スライサーが段差を上面・下面と判定してツールパスが乱れていた。

### 解決策: 断面四角の輪ゴム積層チューブ（Weave Rubber Band Tube）
- 編み重ね選択時限定で、中実モデルのスライス処理を行わず、**「厚み一定（デフォルト 0.40mm = ノズル径相当）の断面四角い輪ゴム（帯状リング）」をレイヤーごとに直接プロシージャル生成して上下に水密マージした中空チューブ構造**を出力する。
- 波の周期に同期して「四角いブロックの立ち上がり・角（エッジ）」の角度に正確に頂点を打つため、エイリアシングノイズが物理的にゼロとなり、完璧にエッジの立った市松模様になる。
- 中身が空洞の薄肉チューブであるため、途中の層に不要な天井・ボトムソリッドインフィルが一切発生せず、100%ペリメータのみでスライスされる。

## 2. 幾何学的設計 (Geometric Algorithm)

### 2.1 頂点の角度配置（適応型サンプリング）
波の周期 `waveCount`（例: 円周 / ピッチ）に基づき、1周期あたりの角を直接頂点として生成する。
- **矩形ブロック（Profile 4: Block Pulse）**:
  1周期あたり以下のキーポイント（角度）に頂点を配置：
  1. `u = 0.0`（谷から山への立ち上がり開始）
  2. `u = edge`（山の頂点到達）
  3. `u = 0.5 - edge`（山頂終了・立ち下がり開始）
  4. `u = 0.5 + edge`（谷底到達）
  これにより、1周期あたり4〜8頂点で、歪み・丸まりのない厳密な矩形波を形成。
- **正弦波・三角波（Profile 2, 3）**:
  1周期あたり12〜16頂点を均等配置し、滑らかな曲線を高精度にサンプリング。

### 2.2 外壁と内壁の半径計算（肉厚 0.40mm 一定）
レイヤー `lay`、角度 `theta`、高さ `z` において：
- 画像からテクスチャの露出率 `exposure`（0.0〜1.0）を取得。
- `stroke = convexVal + concaveVal`
- `h_peak = -concaveVal + stroke * min(1.0, 2.0 * exposure)`
- `h_trough = -concaveVal + stroke * max(0.0, 2.0 * exposure - 1.0)`
- `disp = h_trough + (h_peak - h_trough) * B`
- **外壁半径**: `R_out = R_base + disp`
- **内壁半径**: `R_in = R_out - wallThickness`（デフォルト `wallThickness = 0.40mm`）

### 2.3 上下レイヤーのマージとシェルフ（段差）生成
- レイヤー `lay` の上端（`z = (lay + 1) * t`）と、レイヤー `lay + 1` の下端（`z = (lay + 1) * t`）において：
  - 二つの輪ゴムの水平重なり区間（`[max(R_in_bot, R_in_top), min(R_out_bot, R_out_top)]`）は上下で完全に水密マージ。
  - 外周側の段差（`R_out_bot` と `R_out_top` の差）および内周側の段差（`R_in_bot` と `R_in_top` の差）を、水平シェルフ三角形で塞ぐ。
  - シェルフ三角形のワインディング順序は、v1.5.6で確立した対向エッジ結合則に厳密に従い、オープンエッジ0・法線反転0を保証。
- 最下層（Z=0）および最上層（Z=H）は、`R_in` から `R_out` までの水平なリング面でフタをする。

### 2.4 ツール（色）の割り当て
- 偶数層（`lay % 2 === 0`）の全ポリゴン（外壁・内壁・関連シェルフ）: `toolIds[0]`
- 奇数層（`lay % 2 === 1`）の全ポリゴン（外壁・内壁・関連シェルフ）: `toolIds[1]`
- これにより、スライサー上で完全な 1層1色ツールパス を生成。

## 4. 検証計画

1. **単体幾何検証 (Node.js スクリプト)**:
   - 生成されたチューブメッシュの三角形数、頂点数、エッジ共有整合性を確認。
   - `Directed clashes: 0, Open edges: 0, nonManifold: 0` であることを自動テスト。
2. **モデル視覚確認**:
   - 矩形波の角がトゲトゲにならず、完全な四角い柱（市松模様）になっていることを確認。
   - 内壁が外壁と完全に平行にオフセットされ、肉厚がどこでも 0.40mm 一定であることを確認。
3. **スライサー実機検証**:
   - 出力された3MFをPrusaSlicerでスライスし、
     - 各層に不要な天井・ボトムソリッドインフィルが一切発生しないこと
     - 100%外周ペリメータとして滑らかに印刷パスが生成されること
     を確認。
